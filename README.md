# Protokol Formal Hermes-ProofEngine: Verifikasi Teorema dan Derivasi Matematis Berstandar Internasional

---

## 1. Abstrak
Repositori ini menyajikan **Hermes-ProofEngine**, sebuah sistem penalaran otomatis tingkat tinggi yang dikembangkan untuk mendukung verifikasi teorema matematika, derivasi algoritma, dan analisis teoretis dengan standar rigoritas mutlak. Protokol ini dirancang untuk menghilangkan ambiguasi logis (*handwaving*) dan memastikan setiap langkah deduksi memiliki justifikasi formal yang akurat, memenuhi kaidah riset akademik tingkat atas (standar IEEE/Scopus Q1).

## 2. Metodologi ProofEngine
Sistem ini beroperasi berdasarkan prinsip-prinsip deduksi formal yang ketat, dengan fokus utama pada:

| Komponen | Deskripsi Operasional |
| :--- | :--- |
| **Rigoritas Epistemik** | Penolakan mutlak terhadap argumen intuitif tanpa bukti formal. |
| **Kuantifikasi Eksplisit** | Penggunaan notasi kuantifikasi ($\forall, \exists, \exists!$) dengan ruang domain yang terdefinisi. |
| **Modularisasi Lemma** | Enkapsulasi langkah non-trivial ke dalam bentuk Lemma yang terverifikasi. |
| **Penelusuran Entailment** | Justifikasi langkah deduksi berdasarkan aksioma, definisi, atau teorema terkait. |

## 3. Protokol Templat Riset
Untuk menjaga konsistensi dan standar kualitas tertinggi dalam setiap permintaan, repositori ini menyediakan templat interaksi yang terstandarisasi sebagai berikut:

| Berkas Templat | Kegunaan Utama |
| :--- | :--- |
| `SYSTEM_PROMPT.md` | Konfigurasi inti agen sebagai *ProofEngine*. |
| `QUERY_TEMPLATE.md` | Templat untuk verifikasi teorema standar. |
| `RESEARCH_PROMPT.md` | Templat penulisan paper riset formal (standar Q1). |

## 4. Prosedur Penggunaan
Setiap derivasi harus mengikuti alur penalaran `Hermes-ProofEngine`:
1.  **Formalisasi**: Translasi masalah ke notasi predikat/teori himpunan.
2.  **Strategi**: Penentuan metode deduksi (Contradiction, Induction, Construction, dll.).
3.  **Eksekusi**: Konstruksi langkah demi langkah menggunakan notasi LaTeX terstruktur.
4.  **Audit Adversarial**: Verifikasi mandiri terhadap potensi *logical traps* atau pelanggaran batasan domain.
