# Rumus-Perpangkatan-Universal-4.0

## Deskripsi
Repositori ini berisi protokol formal **Hermes-ProofEngine**, sebuah sistem penalaran otomatis tingkat tinggi yang dirancang untuk verifikasi teorema matematika yang kaku, logis, dan transparan. Protokol ini dikembangkan untuk mendukung standar riset akademik dan implementasi algoritma yang memerlukan rigoritas absolut (standar IEEE/Scopus).

## Protokol ProofEngine
Sistem ini dirancang untuk menghilangkan segala bentuk "handwaving" (argumen intuitif tanpa bukti formal) dan memastikan setiap langkah deduksi memiliki justifikasi eksplisit.

### Struktur Utama
1. **SYSTEM_PROMPT.md**: Definisi instruksi sistem bagi AI untuk bertindak sebagai *ProofEngine*.
2. **QUERY_TEMPLATE.md**: Templat terstandarisasi untuk mengirimkan permintaan teorema agar hasil verifikasi selalu konsisten dan simetris.

## Penggunaan
Untuk melakukan verifikasi teorema, gunakan `QUERY_TEMPLATE.md` saat berinteraksi dengan AI. Pastikan kerangka aksioma (Axiom Framework) didefinisikan dengan jelas dalam setiap permintaan.
